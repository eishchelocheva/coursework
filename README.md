## Описание проекта

В проекте исследуется применение метода **Approximate Bayesian Computation (ABC)** для оценки параметров эпидемиологической SIR-модели с изменяющейся во времени скоростью передачи инфекции.

Рассматривается SIR-модель с тремя временными эпохами:

1. период до введения карантинных ограничений;
2. период действия карантинных ограничений;
3. период после снятия ограничений.

Для каждой эпохи задается свой параметр скорости передачи инфекции:

* `β1` — скорость передачи до карантина;
* `β2` — скорость передачи во время карантина;
* `β3` — скорость передачи после снятия ограничений.

Цель проекта — проверить, насколько точно базовый алгоритм **Rejection ABC** восстанавливает параметры `β1`, `β2`, `β3` по синтетическим наблюдаемым данным с неполной регистрацией случаев заражения.

## Модель

Используется классическая SIR-модель:

```text
S(t) — число восприимчивых индивидов
I(t) — число инфицированных индивидов
R(t) — число выздоровевших / выбывших индивидов
```

Система дифференциальных уравнений:

```text
dS/dt = -β(t) S(t) I(t) / N
dI/dt =  β(t) S(t) I(t) / N - γ I(t)
dR/dt =  γ I(t)
```

Параметр `β(t)` является кусочно-постоянным:

```text
β(t) = β1, 0 ≤ t < t1
β(t) = β2, t1 ≤ t < t2
β(t) = β3, t2 ≤ t ≤ T
```

Базовые параметры синтетического сценария:

| Параметр | Значение | Описание                                   |
| -------- | -------: | ------------------------------------------ |
| `N`      |  `10000` | размер популяции                           |
| `S(0)`   |   `9990` | начальное число восприимчивых              |
| `I(0)`   |     `10` | начальное число инфицированных             |
| `R(0)`   |      `0` | начальное число выздоровевших              |
| `γ`      |    `0.1` | скорость выздоровления                     |
| `β1`     |   `0.25` | скорость передачи до карантина             |
| `β2`     |   `0.08` | скорость передачи во время карантина       |
| `β3`     |   `0.22` | скорость передачи после снятия ограничений |
| `t1`     |     `20` | начало карантинного периода                |
| `t2`     |     `60` | конец карантинного периода                 |

## Наблюдаемые данные

В реальных эпидемиологических данных обычно регистрируется не полное число инфицированных, а только часть случаев. Поэтому в проекте используется биномиальная модель наблюдения:

```text
I_obs(t) ~ Binomial(I(t), p)
```

где:

* `I(t)` — истинное число инфицированных;
* `I_obs(t)` — наблюдаемое число зарегистрированных случаев;
* `p` — вероятность регистрации инфицированного индивида.

## Метод Rejection ABC

В проекте реализован базовый алгоритм **Rejection ABC**.

Схема алгоритма:

1. Сэмплируются кандидатные параметры `β1`, `β2`, `β3` из априорных распределений.
2. Для каждого набора параметров запускается SIR-модель.
3. Получается симулированная траектория инфицированных `I_sim(t)`.
4. Для `I_sim(t)` и `I_obs(t)` вычисляются сводные статистики.
5. Вычисляется расстояние между сводными статистиками.
6. Параметры принимаются, если расстояние не превышает порог `ε`.

Принятые параметры используются как приближенная выборка из апостериорного распределения.

## Основные выводы

1. Метод **Rejection ABC** способен достаточно точно восстанавливать параметры SIR-модели по шумным синтетическим данным.
2. Качество восстановления существенно зависит от выбора порога принятия и набора сводных статистик.
3. Слишком мягкий порог принимает много неточных симуляций.
4. Слишком строгий порог принимает мало параметров и может быть нестабильным.
5. Наиболее сбалансированным оказался порог `q = 0.02`.
6. Увеличение числа симуляций повышает число принятых параметров, но не гарантирует монотонного уменьшения ошибок.
7. Параметр `β3` восстанавливается наиболее устойчиво.
8. Лучший сбалансированный набор сводных статистик — `peak_load_final`.

## Ограничения

В проекте используется базовый алгоритм **Rejection ABC**, который прост в реализации, но имеет ограничения:

* большая часть симуляций отклоняется;
* качество результата зависит от выбора сводных статистик;
* при малом пороге принятия число принятых параметров может быть слишком небольшим;
* результаты зависят от случайности генерации наблюдений и симуляций;
* разные наборы параметров могут давать похожие значения сводных статистик.
